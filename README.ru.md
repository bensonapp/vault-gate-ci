# Vault Gate CI: DevSecOps Пайплайн

Автоматизированный многоэтапный CI/CD конвейер безопасности на базе GitHub Actions. Данный проект демонстрирует практическую интеграцию проверок безопасности в жизненный цикл разработки ПО (SDLC) на примере уязвимого микросервисного REST API (VAmPI).

## Архитектура и инструменты

Пайплайн запускается автоматически при каждом коммите (push) в ветку `main` и реализует три эшелона автоматизированной защиты:

1. **SAST (Статический анализ исходного кода)**
   * **Инструмент:** Semgrep
   * **Цель:** Анализ исходного кода на Python (FastAPI) для выявления логических уязвимостей, хардкод-секретов и небезопасных конфигураций до этапа сборки.

2. **SCA (Анализ компонентной базы ПО)**
   * **Инструмент:** Trivy
   * **Цель:** Поиск известных уязвимостей (CVE) в сторонних зависимостях. Выполняет функцию Security Gate: конвейер блокируется при обнаружении уязвимостей высокой степени риска. Отчеты сохраняются в CI/CD артефакты.

3. **DAST (Динамический анализ)**
   * **Инструмент:** Docker и OWASP ZAP (Baseline Scan)
   * **Цель:** Сборка API и развертывание в изолированном эфемерном Docker-контейнере. OWASP ZAP проводит динамическое сканирование запущенного приложения (`http://localhost:5000`) для выявления проблем конфигурации среды выполнения (отсутствие Security-заголовков, CSRF). Найденные уязвимости автоматически конвертируются в задачи (GitHub Issues).

## Результаты сканирования и триаж

### 1. Архитектура пайплайна и оркестрация
Пайплайн успешно инициализирует виртуальную машину, проводит статический анализ, проверку зависимостей, собирает Docker-образ и атакует его в динамике.

![Successful CI/CD Run](images/success-pipeline.png)

### 2. Работа Шлюза Безопасности (Security Gate)
Пайплайн настроен на жесткую блокировку сборки (exit-code: 1) при обнаружении уязвимостей уровня `HIGH` и `CRITICAL` в зависимостях проекта.

![Trivy Gate](images/trivy-gate.jpg)

### 3. Автоматизация триажа в баг-трекере
После завершения динамического сканирования, OWASP ZAP автоматически конвертирует найденные уязвимости в задачи (Issues) на GitHub для команды разработчиков.

![ZAP Issues](images/zap-issues.png)

### Ключевые выявленные уязвимости
* **Уязвимости зависимостей (SCA):** Обнаружены устаревшие Python-пакеты с уязвимостями высокой степени риска (High CVEs). *Решение:* Жесткая фиксация (pinning) безопасных версий библиотек в `requirements.txt`.
* **Уязвимости среды выполнения (DAST):** OWASP ZAP зафиксировал отсутствие Anti-CSRF токенов и заголовков Content Security Policy (CSP). *Решение:* Внедрение строгих политик CORS и HTTP-заголовков безопасности на уровне middleware FastAPI.

## Конфигурация
Декларативное описание конвейера находится в файле `.github/workflows/sec-pipeline.yml`. Запуск инициируется автоматически при push-событиях в ветку `main`.
